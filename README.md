# Portafolio de David Galvis

**Sitio en vivo:** https://davidgv-ux.github.io/david-galvis-portfolio/

Portafolio bilingüe (ES/EN) de David Galvis, desarrollador full-stack y CTO de fYN. Reúne experiencia, proyectos, stack y contacto en una sola página responsive, sin frameworks.

## Contenido

- `index.html` — sitio completo, con estilos y JavaScript embebidos.
- `assets/` — capturas de fYN y del portafolio 3D, además de la imagen Open Graph.
- `cv-david-galvis.pdf` — CV en español (1 página).
- `cv-david-galvis-en.pdf` — CV en inglés (1 página).

## Actualizar

```bash
git add .
git commit -m "Actualiza el portafolio"
git push
```

GitHub Pages reconstruye el sitio automáticamente desde la rama `main` (raíz del repositorio).

Para probarlo localmente:

```bash
python3 -m http.server 8000
# abre http://localhost:8000
```
